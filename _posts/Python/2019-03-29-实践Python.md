#### 类变量和实例变量

| 对比项   | 类变量                             | 实例变量                              | 局部变量       |
| -------- | ---------------------------------- | ------------------------------------- | -------------- |
| 定义位置 | 类中、方法外，a=1                  | 方法内通过 `self.xxx` 定义，self.b =2 | 方法内，c=3    |
| 属于谁   | 类对象                             | 实例对象                              | 方法           |
| 是否共享 | 所有实例共享一份                   | 每个实例独立一份                      | 否             |
| 访问方式 | `Person.var` 或 `obj.var`          | `obj.var`                             | 方法内         |
| 修改影响 | 修改类变量会影响所有未遮蔽它的实例 | 只影响当前实例                        | 方法内         |
| 典型用途 | 配置、常量、计数器、共享状态       | 姓名、年龄、余额等每个对象独有的数据  | 方法内临时计算 |

**一句话记忆：**

- **类变量 = 整个班级共用的一块黑板。**
- **实例变量 = 每个学生自己的笔记本。**

黑板上的内容所有人都能看到；每个人笔记本上的内容互不影响。

#### self

- **`self` 不是关键字，只是一个普通参数名。**
- **Python 会在调用实例方法时，自动把当前对象作为第一个参数传给它。**
- **通过 `self`，方法可以访问和修改当前对象的实例变量（如 `self.name`），也可以调用当前对象的其他方法（如 `self.hello()`）。**

可以记住一句话：

> **类是"图纸"，对象是"房子"，`self` 就是"这栋房子自己的地址"。方法通过 `self` 才知道该操作哪一栋房子。**

### 类

```python
class Student(object):
    def __new__():
      	print("__new__")
        
    def __init__(self, name, score):
      	print("__init__")
        self.name = name
        self.score = score

    def print_score(self):
        print('%s: %s' % (self.name, self.score))
```

`__new__` 负责**创建对象**

`__init__` 负责**初始化对象**



Python 类的执行可以记住这两条主线：

1、**定义类时**：执行类体中的顶层代码（如类变量赋值、`print` 等），创建类对象；方法只是被定义，不会执行。

2、**实例化对象时**：调用 `类名()` → `__new__()` 创建对象 → `__init__()` 初始化对象 → 返回实例；之后只有显式调用实例方法（如 `obj.method()`）时，对应方法体才会执行。



**类对象（`Person`）**：保存类变量、方法等定义，由 `type` 创建。

**实例对象（`Person()` 返回的对象）**：保存每个实例自己的数据（如 `self.name`、`self.age` 等），**`Person()` 并不是创建类，而是调用类对象来创建一个实例对象。**
