## 基础

### python程序文件

.py结尾，文件头如下：

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
```

或

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
```

区分大小写

### 入口

| 场景                             | 入口                                                         |
| -------------------------------- | ------------------------------------------------------------ |
| 普通 Python 脚本                 | `if __name__ == "__main__": main()`                          |
| Python 包                        | `__main__.py`，使用 `python -m 包名`                         |
| 命令行工具                       | `main()` + `argparse`（或 `click`、`typer`）                 |
| Web 服务（Flask/FastAPI/Django） | 通常由框架启动命令（如 `uvicorn`、`gunicorn`、`manage.py`）调用应用入口，而不是直接执行业务代码 |



### 变量

动态类型，变量的类型有赋值的数据类型决定，且是可以改变的。

```python
a = 12
a = '12'
```

常量一般使用全大写命名

### 数据类型

整数

浮点数

字符串

布尔值：True和False

空值：None

### 数据结构

list

```python
classmates = ['Michael', 'Bob', 'Tracy']
classmates[0]
```

tuple：不可变

```python
classmates = ('Michael', 'Bob', 'Tracy')
```

### 类

```python
class Student(object):
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def print_score(self):
        print('%s: %s' % (self.name, self.score))
```
